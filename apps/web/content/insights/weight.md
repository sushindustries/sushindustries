Sorted by cost, which makes this the answer to a question no directory listing
gives: what is the most expensive thing here to read, and is it expensive
because it is doing something hard or because it grew.

Roughly four thousand tokens is where a page stops being read in one sitting
and an agent stops being able to load it beside anything else. A documentation
page over that has usually absorbed a section that belongs in another tab -
which is exactly what the `simplify` skill is for.
