## What gets posted where

Writing goes on [this site](/posts) first and is not syndicated anywhere. If a
post exists, it is here; if it is somewhere else with my name on it and not
linked from here, treat that as a coincidence of names rather than a
republication.

Releases are visible in each package's page rather than announced. The version
on a component page is the version, and it changes when the component does.

## What is not me

There is no Twitter/X account, no Discord, no Telegram and no newsletter. If
you find one using this name or this mark, it is not mine, and nothing it says
about these packages is something I said.

That list is deliberately explicit. "No account" and "an account I have not
checked in two years" look identical from the outside, and only one of them is
safe to ignore.
