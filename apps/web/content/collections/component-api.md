The `api.md` of every documented component. One section out of five, which is
the whole point: when the question is "what props does this take", the other
four tabs are a hundred thousand tokens of context you did not need.

This is the collection an agent should load before writing markup against this
library, and the reason a collection is a filter rather than a list - a
component documented next week appears here on its own.
