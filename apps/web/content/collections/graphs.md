One diagram per element that has parts. A block is an assembly that stands as
a region of a page; a component is one thing with one job; and the same
components turn up inside several blocks - `icon` is in nine of them.

That last fact is the reason these exist. Reading `folder-shelf`'s registry
entry tells you it needs four things and tells you nothing about three of them
needing `icon` too, which is exactly what you want to know before changing
`icon`.

Generated by `pnpm sushindustries graph`, wholesale, from the registry. Editing
one is pointless - the next run overwrites it. Change the registry.
