The instructions an agent loads before it changes anything in this repository.
Every one of them is a `SKILL.md` under `.claude/skills/`, and every one exists
because something went wrong twice and a rule was cheaper than remembering.

Read this collection when you are about to work here and do not know which
conventions apply. Read the one that matches the change rather than all of
them - that is the first rule in the conventions skill, and it is the rule
about the rules.

Sorted by cost, largest first, because the number that decides whether to load
one is what it will take out of a context window.
