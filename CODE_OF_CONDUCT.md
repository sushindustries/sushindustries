# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be decent. Harassment, personal attacks, and bad-faith
conduct get one warning at most; the full text linked above is the standard
applied, in full.

To report behaviour that violates it, use the contact on my GitHub profile -
GitHub's private vulnerability reporting is for exploitable bugs, not conduct,
so it is the wrong door for this. Reports are read by me, Adam Jurek, because
there is nobody else here - if the report is about me, take it to GitHub's own
[Community Code of Conduct](https://docs.github.com/en/site-policy/github-terms/github-community-code-of-conduct)
channels instead.
