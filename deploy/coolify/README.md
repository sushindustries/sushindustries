# Deploy sushindustries on Coolify

Image: `ghcr.io/sushindustries/sushindustries` (tag `main`, built by `.github/workflows/images.yml`).
Services: `web` (Nitro server, port 3000), `migrate` (one-shot `node migrate.mjs`), `postgres`.

## Steps
1. Coolify: New Resource -> Git repository (sushindustries/sushindustries, branch `main`).
2. Build pack: Docker Compose. Compose location: `deploy/coolify/compose.yaml`.
3. Set the domain on the `web` service (port 3000). Coolify fills `SERVICE_URL_WEB_3000`.
4. Env: copy keys from `deploy/coolify/.env.example`. DB user and password are generated by Coolify.
   Set `GROQ_API_KEY` (for `/api/chat`) and optionally the PostHog keys. Never commit values.
5. Deploy. `migrate` runs once, then `web` starts; probe is `/health`.

Note: `VITE_POSTHOG_*` and `POSTHOG_HOST` are build args, so changing them needs a rebuild.
